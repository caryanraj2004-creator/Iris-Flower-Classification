# Iris Flower Classification

## Project Overview

This project classifies Iris flowers into three species:

* Setosa
* Versicolor
* Virginica

using Machine Learning and Logistic Regression.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn

## Dataset

The project uses the Iris dataset available in Scikit-Learn.

Features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Machine Learning Workflow

1. Load Iris Dataset
2. Convert Dataset to Pandas DataFrame
3. Perform Data Exploration
4. Visualize Data using Histograms
5. Split Data into Training and Testing Sets
6. Train Logistic Regression Model
7. Make Predictions
8. Evaluate Model Accuracy
9. Generate Confusion Matrix

## Results

* Training Samples: 120
* Testing Samples: 30
* Model Accuracy: 100%
